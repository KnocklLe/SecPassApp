    Comment créer le jeton ?
    1. Sur github.com : ta photo › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
    2. Repository access : Only select repositories › ton dépôt SecPass uniquement.
    3. Permissions › Contents : Read and write. Rien d'autre.
    4. Choisis une expiration, génère, copie le jeton et colle-le ici.
